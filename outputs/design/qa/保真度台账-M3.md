## 2. 关键度量（自动化断言）

- 桌面：7 行星期栏等宽 112px；卡片定宽 176px；5 个 Tab、4 个平台 LOGO；今日行高亮；无横向溢出。
- 断点矩阵：375 / 390 / 360 / 768px 全部无溢出；<768 显示星期 Tab + 单日列表，≥768 显示桌面看板。
- 触控：移动端星期 Tab 高 68px（≥44px）；星标视觉 26px、命中区经 `::before` 扩大 9px。
- 交互：平台 Tab 连续切换；星标收藏 → 计数/高亮/「今日追番更新」联动；追番搜索/筛选/展开；日历三视图切换、范围切换、翻页；移动端左右滑动切星期（6→7）；日历方向键（8/1→8/2）。
- 卡片点击：任意卡片触发最新正剧集跳转（实测捕获 `https://v.qq.com/x/page/x0033pef1cg.html` 等真实 URL）。
- 图片：真实海报抽样 10/10 加载成功（`loading="lazy"` + `referrerPolicy="no-referrer"`，失败自动回退 CSS 占位）。
- 无控制台错误、无 page error（全部截图与断言轮次）。

## 3. 本轮修复

1. 海报外链加载失败时回退 CSS 渐变占位（`onError` 隐藏 img，露出占位字形）——真实数据下个别平台图片可能被防盗链。
2. 移动端星期 Tab 补充 `data-mday` 标识（可访问性/测试定位）。
3. M1 遗留：同步管道增加单平台 150s 硬超时、富集请求 8s 超时、工作流步骤 12 分钟上限（已推送 `d7c28f8`）。

## 4. 有意偏差（数据驱动，非布局变更）

- 页头副标题显示真实数据周范围与同步时间（原型为示例固定值）。
- 工具栏说明文案：原型「示例数据 · 仅用于原型审批」→ 线上「四平台定时同步（每日 07:00 / 19:00）」。
- 追番初始为空（原型种子仅用于演示），收藏后日历/今日摘要按真实数据联动。
- 单日 >12 部时显示「+N 部」展开（真实数据多平台聚合后频繁触发，属设计内行为）。
