## 0. 本交付是什么

本包是 G0 阶段的**完整可审批设计原型**，包含：

1. 可交互 HTML 原型（单文件，双击即可离线打开）；
2. 覆盖 §2.2 全部画布清单的 PNG 导出图（存入 `outputs/design/`）；
3. 本设计规范（design spec）：设计 tokens、组件库、响应式规则、交互标注、状态矩阵、数据契约与实现指引。

**合规声明**：本阶段未执行任何实现动作——未建仓、未 `npm install`、未写业务代码、未部署。原型是纯 HTML/CSS/JS 静态文件。

**工具说明**：Figma MCP 服务已连接，但本会话未暴露画布写入工具（`use_figma` / `create_new_file` 等）；imagegen 位图工具同样不可用。按计划 §2.1「工具不限、优先最快产出该质量」的约定，采用**可交互 HTML 原型**路线，PNG 按 §2.3 交付位置输出。

### 3.2 字体

- 字体栈：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`。
- 字号刻度：`11 / 12 / 13 / 15 / 16 / 20 / 26 / 32`（分别用于：角标/标签、弱信息、正文/按钮、强调正文、卡片标题、面板标题、页面主标题、大标题）。
- 字重：400（正文）、500（说明）、600（强调）、700（标题）、800（海报字形装饰）。
- 行高：标题 1.35、正文 1.5；移动端卡片标题最多 2 行省略。

### 3.3 间距 / 圆角 / 阴影

- 间距刻度：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48`（`--s1..--s8`）。
- 圆角：`8（小件）/ 12（卡片）/ 16（面板）/ 22（大面板/横幅）`。
- 阴影：`sm`（卡片常规）、`md`（hover 提升）、`lg`（Toast）。

### 3.4 图标风格

- 线性图标：`stroke-width 1.9–2`、`stroke-linecap/linejoin: round`、24 viewBox、`currentColor` 继承。
- 星标：默认描边，追番后填充 `#F5A623`；Header 追番按钮使用填充星。
- 图标族：日历、星标、刷新、搜索、下载、上传、警告、错误、翻页箭头、返回、外链等，均为同一线性风格。
- **平台品牌 LOGO**：Tab 与筛选 chip 使用各平台品牌标（圆角方形 + 白色图形，17px/15px），原型用简化 SVG（哔哩哔哩 TV 标、腾讯视频 V 标、优酷 U+播放标、爱奇艺 i 标）；M0 可替换为官方透明底资源，尺寸体系不变。

## 8. 数据契约与示例数据说明

### 8.1 数据结构（与 sync 管道输出同构）

```ts
interface AnimeItem {
  id: string; platform: 'bili'|'tencent'|'youku'|'iqiyi';
  title: string; poster: string; episode: string;
  updateTime: string;        // "HH:MM"
  date: string;              // "YYYY-MM-DD"（本周周一 + (dow-1)）
  svip: boolean; url: string; badge?: string;
  duration?: number;         // 秒；<600 会被清洗层丢弃
}
interface FollowItem {
  key: string;               // 规范化标题
  title: string;
  platforms: { platform; url; episode; poster; updateTime }[];
  followedAt: string;
}
```

`updates.json = { generatedAt, platforms: PlatformResult[] }`；追番存 `localStorage["anime-calendar.follows.v1"]`。

### 8.2 语义（用户已确认，原型据此演示）

- `CONTENT_BLOCKLIST`（小课堂/发布会/预告/片花/花絮/幕后/访谈/见面会/先导/抢先看）**仅作用于最新集解析**；周表按平台原始更新数据展示，不做黑名单过滤。
- **追番范围语义**：「今日追番更新」横幅与追番日历（日程/周/月）默认统计**已追番条目**，可在日历中切换「全部番剧」；首页周看板始终展示四平台原始更新数据（不做追番过滤）。
- 跨平台合并：同规范化标题（去 `·`/空格/冒号）在追番列表合并为一个条目，展开多平台行（原型以「大主宰·年番」腾讯+爱奇艺演示）。
- 时长过滤：`duration < 600s` 丢弃；缺失时长对去重后唯一番剧富集，仍缺失则关键词兜底并记入 `warnings`（原型 warnings 横幅演示）。

### 8.3 示例数据声明

原型中的番剧条目为**静态模拟数据**（与管道 `AnimeItem` 同构），仅用于审批视觉与交互；海报为 CSS 渐变占位（按标题哈希取色），实现期替换为各平台真实海报（`loading="lazy"` + 固定尺寸占位 + `referrerPolicy="no-referrer"`）。

## 9. 性能与兼容性约定（移动端）

- `index.html`：`viewport`（含 `viewport-fit=cover`）、`theme-color`。
- 海报懒加载 + 占位；`updates.json` 依赖 Pages gzip；若实际体积 >1MB 或弱网首屏 >3s，则拆分为 `data/{platform}.json` 按 Tab 懒加载（M1 上线后验证的决策点）。
- 兼容：iOS Safari ≥15、Android Chrome/Edge 最新两版、桌面 Chrome/Edge/Firefox 最新两版。
- 动画遵循 `prefers-reduced-motion`；`text-size-adjust` 防 iOS 横屏缩放。
